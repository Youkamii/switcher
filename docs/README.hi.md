## Windows

### इंस्टॉलेशन

**npm से इंस्टॉल करें (अनुशंसित — कोई सुरक्षा चेतावनी नहीं)** — Node.js 18 या उससे ऊपर

```sh
npm install -g switcher-widget
switcher
```

`switcher` कमांड पहली बार चलने पर लेटेस्ट रिलीज़ बिल्ड अपने आप डाउनलोड कर लेती है (उसके बाद तुरंत खुलती है)। यह ब्राउज़र डाउनलोड नहीं है, इसलिए SmartScreen की चेतावनी नहीं आती। अपडेट अपने आप होता है — हर बार चलाने पर नई रिलीज़ की जाँच होती है और अगली बार चलाने पर लागू होती है।

**सीधा डाउनलोड** — [रिलीज़](https://github.com/Youkamii/switcher/releases/latest) से `switcher-win-x64.zip` डाउनलोड करें, unzip करके `switcher.exe` चलाएँ। (Windows 10/11 64-बिट)

- कोड साइनिंग नहीं है, इसलिए पहली बार चलाने पर Windows SmartScreen "अज्ञात प्रकाशक" की चेतावनी दिखा सकता है। `More info` → `Run anyway`।
- वेबव्यू के लिए Windows में पहले से शामिल WebView2 का उपयोग होता है।

### चलाना

- चलते समय यह ट्रे (टास्कबार के दाएँ) में W आइकन के रूप में मौजूद रहता है। विंडो बंद करने (Alt+F4) पर भी बंद नहीं होता।
- विंडो फिर से सामने लाने के लिए ट्रे के W आइकन पर लेफ्ट-क्लिक करें। पूरी तरह बंद करने के लिए ट्रे आइकन पर राइट-क्लिक → बंद करें।
- UI भाषा बदलने के लिए ट्रे आइकन पर राइट-क्लिक → सेटिंग्स → भाषा (한국어·English·日本語·简体中文·繁體中文·हिन्दी)।
- पहली बार चलाने पर डेस्कटॉप पर `switcher` शॉर्टकट अपने आप बन जाता है (हटा देने पर दोबारा नहीं बनता)।
- बूट पर स्वतः चलना डिफ़ॉल्ट रूप से चालू है — ट्रे सेटिंग्स → बूट पर स्वतः चलाएँ से बंद कर सकते हैं।
- हर बार चलाने पर नई रिलीज़ की जाँच करके ऑटो-अपडेट होता है (अगली बार चलाने पर लागू) — ट्रे सेटिंग्स → ऑटो-अपडेट से बंद कर सकते हैं।

## macOS

### इंस्टॉलेशन

**npm से इंस्टॉल करें (अनुशंसित — कोई सुरक्षा चेतावनी नहीं)** — Node.js 18 या उससे ऊपर

```sh
npm install -g switcher-widget
switcher
```

`switcher` कमांड पहली बार चलने पर लेटेस्ट रिलीज़ बिल्ड अपने आप डाउनलोड कर लेती है (उसके बाद तुरंत खुलती है)। यह ब्राउज़र डाउनलोड नहीं है, इसलिए "अज्ञात डेवलपर" की चेतावनी नहीं आती। अपडेट के लिए विजेट बंद करके वही इंस्टॉल कमांड दोबारा चलाएँ।

**सीधा डाउनलोड** — [रिलीज़](https://github.com/Youkamii/switcher/releases/latest) से `switcher-mac-arm64.zip` डाउनलोड करें, unzip करके `switcher.app` चलाएँ। केवल Apple Silicon के लिए — Intel Mac पर नीचे दिए [सोर्स से बिल्ड करें](#सोर्स-से-बिल्ड-करें) से इंस्टॉल करें।

- कोड साइनिंग नहीं है, इसलिए पहली बार खोलने पर "अज्ञात डेवलपर" कहकर रोका जा सकता है। System Settings → Privacy & Security में सबसे नीचे दिखने वाले **Open Anyway** से चलाएँ।

### चलाना

- `switcher.app` चलाएँ। यह Dock और Cmd+Tab में नहीं दिखता; मेन्यू बार के दाएँ W आइकन के रूप में मौजूद रहता है।
- विजेट सभी डेस्कटॉप (Space) और फ़ुल-स्क्रीन ऐप्स के ऊपर ओवरले के रूप में दिखता है।
- विंडो खोलना/छिपाना मेन्यू बार के W आइकन पर लेफ्ट-क्लिक टॉगल से; पूरी तरह बंद करने के लिए राइट-क्लिक → बंद करें।
- UI भाषा बदलना **विकासाधीन** है — फ़िलहाल कोरियाई में दिखता है।
- बूट पर अपने आप शुरू कराने के लिए System Settings → General → Login Items में `switcher.app` जोड़ें।

## परिचय

Claude Code हो या Codex, एक टर्मिनल में एक समय पर सिर्फ़ एक ही अकाउंट लॉगिन रहता है। कई अकाउंट रखने वाले यूज़र को लिमिट भरते ही फिर से `/login` करना पड़ता है, ब्राउज़र ऑथेंटिकेशन दोबारा करना पड़ता है, और यह उलझन भी बनी रहती है कि अभी कौन-सा अकाउंट चल रहा है।

switcher इस पूरी प्रक्रिया को खत्म कर देता है। हर अकाउंट में बस शुरुआत में एक बार लॉगिन कर लें, उसके बाद विजेट में एक बटन से स्विच हो जाता है। हर अकाउंट का उपयोग (5-घंटे·साप्ताहिक लिमिट) बार के रूप में दिखता है, तो देखकर उस अकाउंट पर स्विच करें जिसमें गुंजाइश बची है।

## फ़ीचर्स

- अकाउंट स्विचिंग: दोबारा लॉगिन किए बिना एक बटन। नए खुलने वाले टर्मिनल से लागू होता है।
- उपयोग डिस्प्ले: हर अकाउंट के लिए 5 Hours / Weekly / मॉडल-वार लिमिट और रीसेट तक बचा समय दिखता है।
- अकाउंट जोड़ना: विजेट में दिखने वाले लॉगिन लिंक से कोड लेकर दर्ज करें।
- सब्सक्रिप्शन लेवल: अकाउंट के बगल में Max (5x पीला, 20x लाल) / Pro / Plus दिखता है।
- मोड (Type1/2/3): फ़ुल → विजेट → कॉम्पैक्ट क्रम में बदलता है। विजेट·कॉम्पैक्ट में बटन छिप जाते हैं, क्लिक·ड्रैग पीछे की विंडो तक पास-थ्रू होते हैं, और अकाउंट कार्ड पर डबल-क्लिक से स्विच होता है। विंडो हिलाने के लिए ☰ हैंडल।
- विंडो की ऊँचाई कंटेंट के हिसाब से अपने आप एडजस्ट होती है। ओपैसिटी स्लाइडर घटाने पर पहले बैकग्राउंड, फिर फ़्रेम हल्का होता है।
- UI भाषा: ट्रे → सेटिंग्स → भाषा से 6 भाषाओं (कोरियाई·अंग्रेज़ी·जापानी·सरलीकृत चीनी·पारंपरिक चीनी·हिन्दी) में स्विच। macOS पर विकासाधीन।
- ऑटो-अपडेट·बूट पर स्वतः चलना·डेस्कटॉप शॉर्टकट (Windows): ट्रे सेटिंग्स से चालू/बंद। macOS पर विकासाधीन।
- GitHub अकाउंट स्विचिंग: gh CLI में लॉगिन अकाउंट्स को विजेट से स्विच करें — git push/pull (HTTPS) सक्रिय अकाउंट को फ़ॉलो करता है। उपयोग बार नहीं।
- ब्लैक मॉनिटर (Windows): 🌙 बटन या ट्रे मेनू से सभी स्क्रीनें सबसे ऊपर काले पर्दे से ढक जाती हैं। माउस हिलाने पर कर्सर के आसपास कोहरा छँटने जैसा हिस्सा थोड़ी देर दिखता है; माउस तेज़ी से हिलाएँ या ESC दबाकर बंद करें। macOS पर विकासाधीन।

## यह कैसे काम करता है

दोनों CLI लॉगिन टोकन लोकल में सेव करते हैं।

- Claude Code: `~/.claude/.credentials.json` (Windows) / macOS पर **कीचेन** की "Claude Code-credentials" एंट्री
- Codex CLI: `~/.codex/auth.json` (दोनों OS पर समान)

Mac पर switcher, Claude CLI के ही तरीके से (macOS के बिल्ट-इन `security` टूल से) कीचेन पढ़ता-लिखता है — कोई अलग परमिशन पॉपअप नहीं आता।

switcher हर अकाउंट के टोकन को `~/.switcher/` के नीचे प्रोफ़ाइल के रूप में रखता है और स्विच करते समय दो चरणों में फ़ाइलें बदलता है।

1. पहले मौजूदा सक्रिय फ़ाइल का वर्तमान अकाउंट की प्रोफ़ाइल में बैकअप लेता है। टोकन समय-समय पर अपने आप रिफ़्रेश होते हैं, इसलिए यह चरण पहले होना ज़रूरी है।
2. फिर टार्गेट अकाउंट की प्रोफ़ाइल को सक्रिय स्थान पर कॉपी करता है।

ध्यान दें: अगर टर्मिनल में कोई CLI सेशन चल रहा है, तो उसे बंद करके स्विच करना सुरक्षित है। चालू सेशन टोकन को अपने आप रिफ़्रेश करते हुए सक्रिय फ़ाइल फिर से लिख दे, तो अभी-अभी स्विच किया गया अकाउंट पुराने अकाउंट के टोकन से ओवरराइट हो सकता है।

बातचीत का इतिहास·मेमोरी·सेटिंग्स अकाउंट से स्वतंत्र लोकल फ़ोल्डर में रहते हैं, इसलिए अकाउंट बदलने पर भी वर्क एनवायरनमेंट वैसा ही रहता है।

उपयोग की जानकारी हर अकाउंट के टोकन से, CLI द्वारा इस्तेमाल किए जाने वाले usage API को सीधे क्वेरी करके ली जाती है। रेट लिमिट से बचने के लिए 60 सेकंड का कैश रखा गया है। क्वेरी विफल हो जाए तो पिछला मान दिखाया जाता है।

Claude का एक्सेस टोकन कुछ ही घंटों तक वैध रहता है, इसलिए स्टोर की गई प्रोफ़ाइल का टोकन एक्सपायर होने पर विजेट उसे CLI के ही तरीके से दोबारा जारी कर प्रोफ़ाइल में लिख देता है — ऐप शुरू होते समय एक बार सभी के लिए, उसके बाद क्वेरी के समय सिर्फ़ ज़रूरी के लिए। इसलिए इस्तेमाल में न रहे अकाउंट्स का उपयोग भी हमेशा रीयल-टाइम रहता है। जो अकाउंट अभी इस्तेमाल में है उसका टोकन CLI खुद रिफ़्रेश करता है, इसलिए विजेट उसे नहीं छूता।

अकाउंट जोड़ने का काम आइसोलेटेड लॉगिन से होता है।

## अकाउंट जोड़ना

विजेट में "＋ अकाउंट जोड़ें" दबाने पर लॉगिन URL दिखता है। उस URL को अपनी पसंद के ब्राउज़र में पेस्ट करें।

- **Claude**: ब्राउज़र में लॉगिन करने पर स्क्रीन पर एक कोड दिखता है। वह कोड विजेट के इनपुट बॉक्स में पेस्ट करते ही काम पूरा।
- **Codex**: विजेट में URL के साथ एक वन-टाइम कोड (15 मिनट वैध) दिखता है। ब्राउज़र में वह कोड दर्ज करें, बाकी अपने आप हो जाता है।

**पहली बार Codex जोड़ने से पहले**: डिवाइस कोड ऑथेंटिकेशन OpenAI अकाउंट में डिफ़ॉल्ट रूप से बंद रहता है। इसे चालू किए बिना कोड दर्ज करने पर "डिवाइस कोड ऑथेंटिकेशन सक्षम करके फिर से चलाएँ" कहकर अस्वीकार कर दिया जाता है।

- व्यक्तिगत अकाउंट: chatgpt.com → प्रोफ़ाइल → सेटिंग्स → सुरक्षा (या डेटा कंट्रोल) → **Codex डिवाइस कोड ऑथेंटिकेशन** चालू करें
- टीम·बिज़नेस अकाउंट: एडमिन वर्कस्पेस सेटिंग्स → परमिशन और रोल्स से सक्षम करे

नोट: Claude CLI लॉगिन शुरू करते समय डिफ़ॉल्ट ब्राउज़र एक बार खोलने की कोशिश करता है। उस विंडो को बंद कर सकते हैं; विजेट का URL पेस्ट किए हुए ब्राउज़र में आगे बढ़ें।

## GitHub अकाउंट स्विचिंग

[GitHub CLI (gh)](https://cli.github.com) इंस्टॉल हो तो विजेट में GITHUB सेक्शन दिखता है। हर अकाउंट के लिए टर्मिनल में एक बार `gh auth login` कर लें, फिर विजेट से स्विच कर सकते हैं — अंदरूनी तौर पर यह `gh auth switch` वाला ही रास्ता लेता है, और हर स्विच पर `gh auth setup-git` चलाता है ताकि git push/pull (HTTPS) सक्रिय अकाउंट को फ़ॉलो करे। टोकन gh के keyring में रहते हैं; विजेट उन्हें नहीं छूता।

ज्ञात सीमाएँ:

- SSH रिमोट (`git@github.com:...`) पर असर नहीं — पहचान SSH कुंजी तय करती है। केवल HTTPS रिमोट।
- कमिट author (`git config user.name/email`) नहीं बदलता — स्विच के बाद भी कमिट में पुराना नाम रहता है।
- VS Code, Copilot आदि अन्य ऐप्स के GitHub सेशन अपने टोकन रखते हैं, वे फ़ॉलो नहीं करते।
- SAML SSO वाले organization रिपॉज़िटरी के लिए हर अकाउंट की SSO स्वीकृति ज़रूरी है।

## तकनीक

Tauri 2 + Rust, फ़्रंटएंड वनीला TypeScript। अकाउंट स्विचिंग·उपयोग क्वेरी·आइसोलेटेड लॉगिन — सब कुछ Rust में हैंडल होता है।
वेबव्यू तक टोकन कभी नहीं पहुँचता।
CLI की लॉगिन स्क्रीन वर्चुअल कंसोल (PTY) से पढ़ी जाती है।

## सोर्स से बिल्ड करें

बिल्ड डाउनलोड करने के बजाय सोर्स से बिल्ड करना हो तो [Node.js](https://nodejs.org) और [Rust](https://rustup.rs) टूलचेन चाहिए।

```sh
git clone https://github.com/Youkamii/switcher.git
cd switcher
npm run setup
```

`npm run setup` डिपेंडेंसी इंस्टॉल और ऐप बिल्ड एक साथ कर देता है। लंबे-चौड़े लॉग की जगह सिर्फ़ लोडिंग इंडिकेटर और बीता हुआ समय दिखाता है।

पहली बार पूरा Rust कंपाइल होता है, इसलिए **5–10 मिनट लग सकते हैं।** लोडिंग अटकी नहीं है, बस इंतज़ार करें। आउटपुट: Windows में `src-tauri\target\release\switcher.exe`, macOS में `src-tauri/target/release/bundle/macos/switcher.app` — ऐप को Applications फ़ोल्डर में भी ले जा सकते हैं।

डेवलपमेंट रन के लिए `npm run tauri dev`।
